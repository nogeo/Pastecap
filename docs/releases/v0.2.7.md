## 更新内容

- 修复启动后只在后台运行、看不到页面的问题：启动时自动显示历史面板。
- 修复已运行时双击应用没有反应的问题：再次从 Finder 打开会重新显示历史面板。
- 保留菜单栏入口、快捷键和已有剪贴板历史。

## 下载与安装

- Apple Silicon（M 系列）：下载 `Pastecap-arm64.dmg`。
- 64 位 Intel：下载 `Pastecap-x86_64.dmg`。
- 要求 macOS 14.0 或更新版本。

先退出旧版，将 DMG 中的 Pastecap 拖入 Applications 替换，然后打开应用。

安装包尚未经过 Apple 公证。若 macOS 拦截，请在「系统设置 → 隐私与安全性」中点击「仍要打开」，按系统提示确认。截图需要单独授予屏幕录制权限。

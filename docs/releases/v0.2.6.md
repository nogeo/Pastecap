## 更新内容

此版本包含未成功发布的 v0.2.5 的全部修复。

- 显式保留缩略图位图的原始像素尺寸与显示尺寸，修复 ARM、Intel CI 上图片表示类型差异导致的测试失败。

- 修复截图画笔标注导出时未转换选区坐标，导致结果图丢失标注的问题；保留普通和 Retina 截图的原生分辨率。
- 完成、保存或贴图前自动提交正在输入的文字标注。
- 修复清空历史时后台图片任务可能重新添加已清除记录的问题。
- 图片与历史记录保存失败时显示提示，支持重试历史保存；退出前检查未保存的记录。
- 截图使用唯一文件名，避免同一秒保存时覆盖已有截图。
- 剪贴板监听保留轮询兜底，减少系统更新导致监听失效的影响。
- 新增 ARM、Intel 双架构 CI，发布安装包前执行测试和 Release 构建。

## 下载与安装

- Apple Silicon（M 系列）：`Pastecap-arm64.dmg`。
- 64 位 Intel：`Pastecap-x86_64.dmg`。
- 要求 macOS 14.0 或更新版本。

打开 DMG，将 Pastecap 拖入 Applications 文件夹。区域截图需要在系统设置中授予屏幕录制权限。

安装包使用 ad-hoc 签名，尚未经过 Apple 公证；首次打开可能需要在系统设置中允许打开。
